# The Midnight Library

A dark academia-inspired AO3 skin with a variety of gold ornaments <3

# SKIN FILES

The Midnight Library consists of three complementary CSS files:

- [Combined CSS](The-Midnight-Library-Combined.css)
- [PC CSS](The-Midnight-Library-PC.css)
- [Mobile CSS](The-Midnight-Library-Mobile.css)

!!! All three skins are required for the complete experience.
They are designed to work together rather than independently !!!

# CREATING A NEW SITE SKIN

You will need an AO3 account and must be logged in to install this site skin.

## STEP 1 — Creating the PC Skin

1. Open the PC CSS file linked above and copy the entire code.
2. Log into your AO3 account.
3. Click on your username at the top of the page.
4. Select **Dashboard** from the dropdown menu.
5. Go to **Skins**.
6. Click on **Create Site Skin**.
7. Give your skin a unique title, such as "The Midnight Library - PC - YourUsername".
8. Paste the copied code into the CSS box.
9. Click **Submit** to save your skin.

Do not click **Use** yet.

## STEP 2 — Creating the Mobile Skin

1. Open the Mobile CSS file and copy the entire code.
2. Create another site skin.
3. Give it a unique title, such as "The Midnight Library - Mobile - YourUsername".
4. Paste the copied code into the CSS box.
5. Click **Submit** to save your skin.

Do not click **Use** yet.

## STEP 3 — Creating the Combined Skin

1. Open the Combined CSS file and copy the entire code.
2. Create another site skin.
3. Give it a unique title, such as "The Midnight Library - Combined - YourUsername".
4. Paste the copied code into the CSS box.
5. Scroll down to **Advanced** and click **Show**.
6. Locate the **Parent Skins** section.
7. Add your PC skin as the first parent skin.
8. Click **Add parent skin** and add your Mobile skin as the second parent skin.
9. Click **Submit** to save your skin.

## STEP 4 — Activating the Skin

Once all three skins have been created and linked, open your Combined skin and click **Use**.

You only need to activate the Combined skin.

Enjoy The Midnight Library!
